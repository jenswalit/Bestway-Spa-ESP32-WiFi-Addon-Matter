# Matter koppelen

De module gebruikt Matter via WiFi. De setupgegevens worden bij de eerste
initialisatie van een nieuwe module aangemaakt en bewaard. OTA hoort deze
credentials en de bestaande fabrics te behouden.

## Eerste koppeling

Open de Matter-instellingen op de webpagina. Gebruik de vaste apparaatcode of QR
van jouw eigen module om de eerste controller toe te voegen. Deel die code niet
openbaar; een code op een voorbeeldfoto is niet jouw code.

## Een extra ecosysteem

Gebruik **Nieuwe koppeling openen** en vervolgens de tijdelijke code/QR voor het
nieuwe koppelvenster. Bestaande Google Home-, Apple Home- of HA-fabrics blijven
staan. Wis geen fabrics om een tweede controller toe te voegen.

Het aantal fabrics telt Matter-koppelingen. Bij koppelen via iOS kan naast een
Google-koppeling ook een platformfabric aanwezig zijn. Dat betekent niet vanzelf
dat de spa al in de Apple Woning-app zichtbaar is.

De [handleiding](PtW_Spa_Control_Handleiding.pdf) beschrijft de telefoons en hubs.
Gewone logging hoort de codes niet te publiceren. Een expliciete Matter-reset is
een afzonderlijke gebruikersactie; gebruik die niet bij een normale update.
